SWP08 作業指南與 Teachable Machine 步驟

本遊戲符合 SWP08 的四大要求：

  • 類別訓練：支援 2 種以上動作 (如: Jump 跳躍, Idle 站立/蹲下)。
  • 鏡頭/信心分數：即時畫面顯示，以及動態條狀圖呈現百分比信心分數。
  • 互動效果：觸發動作時產生畫面綠光脈衝、動態跳躍、聲音音效與 Log。
  • 部署專案：單一 HTML 檔，可直接上傳並部署至 GitHub Pages！

📖 Teachable Machine 訓練與套用 3 步驟：

  1. 前往 Teachable Machine：
    開啟 Teachable Machine Pose (姿勢) 或 Image (圖片) 專案。
  2. 新增並訓練 2 個類別 (Class)：
    • 類別 1 命名為 Jump (代表跳躍，錄製舉手或跳躍姿勢)
    • 類別 2 命名為 Idle (代表一般狀態，錄製正常坐著/站著)
  3. 匯出並貼上 Model 網址：
    點選 Export Model ➔ 點擊 Upload (shareable link) ➔ 複製獲得的 URL (例如 https://teachablemachine.withgoogle.com/models/xxxx/) 貼到本頁右上方輸入框即可！
